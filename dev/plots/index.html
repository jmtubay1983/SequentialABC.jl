Plotting

SequentialABC.jl ships a lightweight, optional plotting API that reproduces the common pyABC visualisations:

FunctionpyABC analogueShows
plot_marginalsplot_kde_1d1‑D marginal posteriors
plot_pairsplot_pairwise_heatmappairwise joint posteriors (corner plot)
plot_traceplot_traceweighted parameter means per generation
plot_diagnosticsplot_eps / plot_essε, ESS and attempt counts
plot_ppcplot_ppcposterior predictive check

Optional, lazy backends

Plotting backends are not dependencies of the package. Plots.jl (and StatsPlots.jl, used for the corner plot) are loaded lazily — and only when a plotting function is called with backend = :plots — via Requires.jl.

Calling a function with backend = :none returns a dependency‑free PlotSpec describing the figure instead of rendering it, which keeps the package test suite free of plotting dependencies.

Setup

The plotting dependencies live in a small example environment:

using Pkg
Pkg.activate("examples/plots_env")
Pkg.instantiate()

Usage

using SequentialABC
using Plots
using StatsPlots

# `history` is a vector of per-generation states — e.g. loaded from checkpoints:
#   history = [load_checkpoint(p, cfg) for (_, p) in list_checkpoints(ckpt)]
history = [load_checkpoint(p, cfg) for (_, p) in list_checkpoints(ckpt)]

p1 = plot_marginals(history; labels = ["μ", "σ"])
p2 = plot_pairs(history; labels = ["μ", "σ"])
p3 = plot_trace(history; labels = ["μ", "σ"])
p4 = plot_diagnostics(history)
p5 = plot_ppc(history, s_obs)

savefig(p1, "marginals.png")

A complete, runnable example that writes all five figures to repro/plots/ lives in examples/plot_examples.jl:

julia --project=examples/plots_env examples/plot_examples.jl

API

SequentialABC.plot_marginals — Function
plot_marginals(history; backend=:plots, labels=nothing, nbins=30)

One‑dimensional marginal posteriors of every parameter, drawn as weighted histograms with the posterior mean marked.

history is either a single ABCSMCState or a vector of per‑generation states (the last generation is plotted). Returns a Plots.jl figure when backend = :plots, or a PlotSpec when backend = :none.

source
SequentialABC.plot_pairs — Function
plot_pairs(history; backend=:plots, labels=nothing, seed=0)

Pairwise joint posteriors (a pyABC‑style corner plot). Particles are resampled according to their importance weights with the deterministic seed, so the figure is reproducible.

history is either a single ABCSMCState or a vector of per‑generation states. Returns a Plots.jl figure when backend = :plots, or a PlotSpec when backend = :none.

source
SequentialABC.plot_trace — Function
plot_trace(history; backend=:plots, labels=nothing)

Weighted posterior mean of each parameter as a function of the generation index. history must contain one state per generation (e.g. loaded from checkpoints). Returns a Plots.jl figure when backend = :plots, or a PlotSpec when backend = :none.

source
SequentialABC.plot_diagnostics — Function
plot_diagnostics(history; backend=:plots)

ABC‑SMC run diagnostics across generations: the tolerance ε, the effective sample size (ESS) and the number of simulation attempts spent in each generation. Returns a Plots.jl figure when backend = :plots, or a PlotSpec when backend = :none.

source
SequentialABC.plot_ppc — Function
plot_ppc(history, summary_obs; backend=:plots, nbins=20)

Posterior predictive check: distribution of the simulated summaries of the final population against the observed summary summary_obs. For multi‑component summaries the first component is used. Returns a Plots.jl figure when backend = :plots, or a PlotSpec when backend = :none.

source
SequentialABC.PlotSpec — Type
PlotSpec

Dependency‑free description of a figure, returned by the plotting functions when called with backend = :none.

Fields:

  • kind::Symbol — one of :marginals, :pairs, :trace, :diagnostics, :ppc
  • data::NamedTuple — the extracted, ready‑to‑plot data
  • options::NamedTuple — rendering options supplied by the caller

PlotSpec holds only plain arrays and scalars, so it can be stored, compared or serialised without loading any plotting backend — useful for smoke tests.
