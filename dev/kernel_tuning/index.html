Kernel tuning helpers

AdaptiveKernel adapts the whole covariance of the perturbation ( \theta' \sim \mathcal{N}(\theta, \Sigma) ). When what you want instead is an explicit, inspectable per‑dimension bandwidth — for a product kernel, a sweep over scalings, or a proposal built outside the engines — the three helpers on this page each make one choice, and make_adaptive_kernel composes them.

Everything here is pure and RNG‑free: the same population always yields the same bandwidths, and nothing is wired into the engines automatically.

Scaling rules

auto_kernel_scale(d; rule, factor) returns a scalar factor for a d‑dimensional covariance. It covers the scaling_factor rules (:rosenthal, :beaumont, :unit, or any real) and adds two dimension‑only bandwidth heuristics:

rulefactoruse
:rosenthal / :gelman( 2.38^2 / d )classic optimal random‑walk scaling (Gelman, Roberts & Gilks 1996)
:beaumont / :abc( 2 )ABC‑SMC perturbation scaling (Beaumont et al. 2009)
:unit / :none( 1 )no scaling
:silverman( (4/(d+2))^{1/(d+4)} )Silverman's rule‑of‑thumb bandwidth
:median( 2\,\mathrm{median}(\chi^2_d)/d )dimension‑only median heuristic
a Realthe valueany custom factor
auto_kernel_scale(4)                      # 2.38² / 4 = 1.4161
auto_kernel_scale(4; rule = :silverman)   # (4/6)^(1/8) ≈ 0.9509
auto_kernel_scale(2; rule = :median)      # 2·log 2 ≈ 1.3863
auto_kernel_scale(4; factor = 0.5)        # half the Rosenthal factor

:median is the median heuristic in dimension‑only form: with no data to measure, it uses the median of the ( \chi^2_d ) distribution — the typical squared distance of a standard Gaussian in ( d ) dimensions.

A positive‑definite covariance

shrinkage_covariance(X; λ = 1e-6) is the Ledoit–Wolf‑style shrinkage of the sample covariance towards isotropy,

[ \Sigma = (1-\lambda) S + \lambda \frac{\operatorname{tr} S}{d} I , ]

the same family used by estimate_covariance. A positive λ makes the result positive definite for degenerate input — repeated rows, ( N \le d ), a single row — where the plain sample covariance is singular and a Cholesky factorisation would fail. A population with no variance information at all falls back to ( \lambda I ).

Σ̂ = shrinkage_covariance(matrix_of_samples)   # PD even if the rows repeat

Bandwidths from a covariance

bandwidth_from_cov(cov; method, min_bandwidth) reads per‑dimension standard deviations off a covariance:

  • :diag (default) — the marginal standard deviations, sqrt.(diag(cov));
  • :full — the diagonal of the Cholesky factor, i.e. the conditional standard deviations ( \mathrm{sd}(\thetai \mid \theta1 \dots \theta_{i-1}) ), which reduce to :diag for a diagonal covariance and stay smaller under correlation.

Both are floored at min_bandwidth (default 1e-8) so a zero‑variance dimension is still usable.

Putting it together

make_adaptive_kernel(cfg; method = :auto, min_scale = 1e-6, rule = :rosenthal) returns a small callable that maps a particle population to bandwidths:

using SequentialABC

tuner = make_adaptive_kernel(cfg)     # cfg fixes the dimension
bw    = tuner(state.θ)                # per-dimension bandwidths, length d

The pipeline is exactly the three helpers: shrink the population covariance, read bandwidths with method (:auto chooses :full when some pair of dimensions is correlated beyond 0.1, and :diag otherwise), scale by auto_kernel_scale(d; rule), and floor at min_scale.

Because the result is a vector of scales and not a kernel, installing it is explicit — through the existing covariance plumbing, with no engine changes:

bw = tuner(state.θ)
state.cfg = with_covariance(state.cfg, Matrix(Diagonal(bw .^ 2)))
run_generation!(state, s_obs; ε = epsilon_quantile(state, 0.5))

For a directly correlated proposal, use AdaptiveKernel, which adapts the full covariance in place; these helpers are for callers that want the per‑dimension view.

API

SequentialABC.auto_kernel_scale — Function
auto_kernel_scale(d::Integer; rule = :rosenthal, factor = 1.0) -> Float64

Scaling factor that turns an estimated d-dimensional covariance into a proposal covariance — the same rules as scaling_factor, plus two bandwidth-selection heuristics whose only input is the dimension:

rulefactoruse
:rosenthal (alias :gelman)2.38² / dclassic optimal random‑walk scaling (Gelman, Roberts & Gilks 1996)
:beaumont (alias :abc)2ABC‑SMC perturbation scaling (Beaumont et al. 2009)
:unit (alias :none)1no scaling
:silverman(4/(d+2))^(1/(d+4))Silverman's rule‑of‑thumb bandwidth
:median2·median(χ²_d)/ddimension‑only median heuristic
::Realthe valueany custom factor

The result is multiplied by factor (a positive real, default 1.0), which is the knob for a coarse global adjustment without touching the rule.

:silverman is Silverman's (4/(d+2))^(1/(d+4)) bandwidth factor for a Gaussian kernel. :median has no data to work with here, so it uses the median of the chi-squared distribution with d degrees of freedom — the typical squared distance of a standard Gaussian in d dimensions — giving 2·median(χ²_d)/d (for d = 2 this is 2·log 2 ≈ 1.386).

An unknown rule, a non‑positive factor, or d < 1 raises an ArgumentError.

SequentialABC.shrinkage_covariance — Function
shrinkage_covariance(X::AbstractMatrix; λ = 1e-6) -> Matrix{Float64}

Ledoit–Wolf‑style shrinkage covariance of the rows of X (an N × d matrix): the unbiased sample covariance pulled towards isotropy,

Σ = (1 − λ) S + λ (tr S / d) I,

symmetrised. The target is the scalar mean of the sample variances, so λ = 1 gives a purely isotropic estimate and λ = 0 the plain sample covariance.

λ > 0 (the default 1e-6) makes the result positive definite even for a rank‑deficient population — repeated rows, N ≤ d, a single row — which is what keeps a Cholesky factorisation of the proposal from failing. A population with no variance information at all (fewer than two rows, or every row identical) falls back to λ · I, mirroring estimate_covariance's degenerate‑population rule; λ = 0 does not guarantee positive definiteness. λ must lie in [0, 1].

SequentialABC.bandwidth_from_cov — Function
bandwidth_from_cov(cov; method = :diag, min_bandwidth = 1e-8) -> Vector{Float64}

Per‑dimension bandwidths (standard deviations) read off a covariance matrix.

  • method = :diag — the marginal standard deviations, sqrt.(diag(cov)).
  • method = :full — the diagonal of the Cholesky factor, i.e. the conditional standard deviations sd(θᵢ | θ₁…θᵢ₋₁) of the same Gaussian covariance. Reduces to :diag when cov is diagonal, and stays smaller when dimensions are correlated.

Every bandwidth is floored at min_bandwidth (default 1e-8), so a zero‑variance or near‑zero dimension still yields a usable positive scale. cov must be square and symmetric; method = :full additionally requires positive definiteness, and an unknown method or a non‑positive min_bandwidth raises an ArgumentError.

SequentialABC.make_adaptive_kernel — Function
make_adaptive_kernel(cfg; method = :auto, min_scale = 1e-6,
                     rule = :rosenthal) -> TunedKernel

Build a callable that reads per‑dimension bandwidths off a particle population, composing the three helpers above:

  1. shrinkage_covariance of the population (so a degenerate population still yields a positive‑definite matrix),
  2. bandwidth_from_cov with method (:auto picks :full when some pair of dimensions is correlated beyond 0.1 and :diag otherwise),
  3. scaling by auto_kernel_scale(d; rule) and flooring at min_scale.

cfg supplies the dimension (size(cfg.Σ, 1)), and is validated eagerly — an unknown method/rule, min_scale ≤ 0, or a config without a covariance field fails at construction rather than at the first call.

The result is a pure function of the particles: no RNG, no engine state, and the same population always yields the same bandwidths. It is not wired into the engines — install the bandwidths yourself through the existing covariance plumbing:

tuner = make_adaptive_kernel(cfg)
bw    = tuner(state.θ)                                   # per-dimension scales
state.cfg = with_covariance(state.cfg, Matrix(Diagonal(bw .^ 2)))

For a directly correlated proposal, AdaptiveKernel already adapts the full covariance; this helper is for callers that want explicit, inspectable per‑dimension scales.
