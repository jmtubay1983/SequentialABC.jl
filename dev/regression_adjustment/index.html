Regression adjustment

Accepting particles with a finite tolerance (\epsilon) distorts an ABC posterior: the accepted parameters are correlated with the deviation of their simulated summaries from the observed summary, which biases the posterior and inflates its variance. Regression adjustment (the ABC regression correction) removes the leading part of that distortion by regressing the parameters on the summaries.

Given accepted particles ((\thetai, si)) with importance weights (wi) and the observed summary (s{\text{obs}}), the corrected parameters are

[ \thetai^{\star} = \thetai - \hat{\beta}^{\top} (si - s{\text{obs}}), ]

where (\hat{\beta}) is a (weighted) least-squares fit of (\theta) on (s).

Method(\hat{\beta})Reference
OLSweighted linear fit of (\theta) on (s)Beaumont, Zhang & Balding (2002)
local linearkernel-weighted fit centred at (s_{\text{obs}})Blum & François (2010)

The local-linear variant also corrects the heteroscedasticity of the ABC acceptance kernel (distant particles are noisier) and is usually the better default. Both estimators are weighted least squares: they are fully deterministic and depend only on LinearAlgebra and Statistics, so no extra packages are pulled in.

Adjusting a run

adjusted_posterior accepts an existing result object and returns a result of the same structure with the particles replaced by their adjusted values:

using SequentialABC

adjusted = adjusted_posterior(state;                       # state::ABCSMCState
                              summaries_fn = s -> [s],     # one summary -> regressors
                              observed_summary = s_obs,
                              method = :local_linear)

adjusted.θ          # adjusted particles — plot with plot_marginals(adjusted)
adjusted.w          # weights are unchanged

method = :ols switches to the plain linear correction; for the local-linear method the bandwidth h and the kernel can be overridden:

adjusted_posterior(state; summaries_fn = s -> [s], observed_summary = s_obs,
                   method = :local_linear, kernel = :epanechnikov, h = 0.2)

Adjusting plain arrays

The low-level entry points operate on arrays and return the adjusted parameter matrix, so they can also be used outside the sampler:

θ_ols = ols_adjust(Θ, S, s_obs)                    # Θ: N×d, S: N×q
θ_ll  = local_linear_adjust(Θ, S, s_obs; kernel = :gaussian)

Both accept optional importance weights w and return an N × d Matrix{Float64}. The matching array-level adjusted_posterior(Θ, S, s_obs) instead returns a RegressionAdjustment that also exposes the fitted slopes and the bandwidth actually used.

Example

A runnable demonstration lives in examples/regression_adjustment.jl:

julia --project=. examples/regression_adjustment.jl

It runs a tiny ABC-SMC on a linear-Gaussian model, applies both corrections and shows that the adjusted posterior has the correct mean with a smaller spread.

References

  • Beaumont, M. A., Zhang, W., & Balding, D. J. (2002). Approximate Bayesian computation in population genetics. Genetics, 162(4), 2025–2035.
  • Blum, M. G. B., & François, O. (2010). Non-linear regression models for Approximate Bayesian Computation. Statistics and Computing, 20(1), 63–73.

API

SequentialABC.ols_adjust — Function
ols_adjust(samples, summaries, observed_summary; w=nothing) -> Matrix{Float64}

Linear (OLS) regression adjustment of ABC particles (Beaumont, Zhang & Balding 2002).

samples is the N × d matrix of accepted parameters (a vector of parameter vectors or a vector of scalars is also accepted), summaries the N × q matrix of their simulated summaries and observed_summary the observed summary. The optional importance weights w give a weighted least-squares fit. Returns the adjusted N × d parameters

θ*_i = θ_i − β̂ᵀ (s_i − s_obs).
source
SequentialABC.local_linear_adjust — Function
local_linear_adjust(samples, summaries, observed_summary;
                    w=nothing, kernel=:epanechnikov, h=nothing) -> Matrix{Float64}

Local-linear regression adjustment (Blum & François 2010): the same correction as ols_adjust, but the slopes β̂ come from a kernel-weighted fit centred at observed_summary, which also corrects the heteroscedasticity of the ABC acceptance kernel.

kernel is one of :epanechnikov (default), :gaussian or :uniform. h is the bandwidth; when omitted it defaults to Silverman's rule-of-thumb on the summary scale, enlarged if necessary so the window contains at least q + 2 particles. Returns the adjusted N × d parameters.

source
SequentialABC.adjusted_posterior — Function
adjusted_posterior(result; summaries_fn, observed_summary, method=:ols, kwargs...)

Regression-adjust an existing sampler result and return a result of the same structure with the particles replaced by their adjusted values.

  • result — an ABCSMCState (a NamedTuple with θ, summaries and optionally w fields also works);
  • summaries_fn — maps one stored summary to a vector of regressors, e.g. s -> [s] for scalar summaries (identity for vector summaries);
  • observed_summary — the summary the run was conditioned on;
  • method — :ols or :local_linear;
  • kwargs... — forwarded to local_linear_adjust (kernel, h) when method = :local_linear.
adjusted = adjusted_posterior(state;
                              summaries_fn = s -> [s],
                              observed_summary = s_obs,
                              method = :local_linear)

The complementary array-level method

adjusted_posterior(samples, summaries, observed_summary; method=:ols, w=nothing,
                   kernel=:epanechnikov, h=nothing) -> RegressionAdjustment

returns a RegressionAdjustment with the adjusted particles together with the fitted slopes and bandwidth.

SequentialABC.RegressionAdjustment — Type
RegressionAdjustment

Result of the array-level adjusted_posterior. Holds the adjusted particles together with the fitted regression.

Fields:

  • θ::Matrix{Float64} — adjusted parameters (N × d)
  • weights::Vector{Float64} — importance weights (normalised)
  • method::Symbol — :ols or :local_linear
  • kernel::Symbol — kernel used (:local_linear only)
  • bandwidth::Union{Nothing,Float64} — kernel bandwidth (:local_linear only)
  • slope::Matrix{Float64} — estimated regression slopes (q × d)
