# Citation

If you use SequentialABC.jl in academic work, please cite it as:

```
Tubay, J. (2026). SequentialABC.jl (v0.1.0) [Software]. GitHub. https://github.com/jmtubay1983/SequentialABC.jl (commit: 3f352e7)
```

Machine-readable metadata is provided in [`CITATION.cff`](CITATION.cff), which
GitHub renders as a "Cite this repository" button. The `doi:` field there is a
placeholder (`DOI_GOES_HERE`) until a DOI is minted.
